PCBs (Printed Circuit Boards) are specialty parts that require some electronics knowledge and experience to properly order.  It is an entire subject in itself.  As Carrie Sundra has very specific knowledge of this board, we recommend you hire her if you need assistance in ordering and then programming these custom circuit boards.

For those of you familiar with ordering custom PCBs:
All the gerbers are here including 2 hole files.  This PCB does include plated slots.  The board was originally designed ages ago with Altium, so the Gerber extensions reflect their format (GKO = board outline).  The original Altium files are also included, it's possible that KiCad will do a good job with the import, but I haven't tried.  

You'll notice there are 3 BOM files.  "BOM for Quotes" is a BOM using mostly Digi-Key parts, useful if you're doing assembly yourself or contracting it out to a fab house in the USA (which will be way too expensive).  "BOM for JLC" is an Excel file showing the LCSC equivalents of the Digi-Key parts.  "Pick Place BOM" is the actual file you should upload to JLC or any other Chinese online quoting system that uses the LCSC parts.
